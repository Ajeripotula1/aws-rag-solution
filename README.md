# AWS Multi-Agent System with RAG on Bedrock Knowledge Bases, S3 and CI/CD (Strands + AgentCore)

## Day 1: Bedrock call
- `uv` project with ruff; AWS CLI profile `dev`
- CLI that sends a prompt to a Bedrock model (Converse API)

## Day 2: AgentCore + Strands agents
- AgentCore project with an orchestrator routing to specialist agents (agents as tools)
- FAQ agent with mocked keyword retrieval
- Account agent (read-only) and refund agent over local test data

## Day 3: Data and Lambda tools
- CDK data stack: DynamoDB customers, orders and events tables, plus a seed script
- Orders Lambda behind the account and refund agent tools

## Day 4: RAG with Bedrock Knowledge Base
- FAQ PDF generated by a script and uploaded to S3 by the data stack
- Knowledge Base on S3 Vectors; FAQ agent retrieves from it with a relevance cutoff
- Runtime deployed to AgentCore with Knowledge Base and Lambda permissions
